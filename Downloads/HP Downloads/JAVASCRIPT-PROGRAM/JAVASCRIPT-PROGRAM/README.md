# JAVASCRIPT-PROGRAM — Function Types Assignments

This folder contains answers to all 22 assignments about named functions, function expressions, arrow functions, and mixed scenarios.

## Folder contents
- `function.html` — opens in a browser and loads one JavaScript file.
- `01-simple-interest.js` through `22-bmi-report.js` — separate answer files.
- `QUESTIONS-AND-ANSWERS.md` — questions, solutions, and sample outputs.

## Run a program using Inspect / Console (no Node.js required)
1. Open this folder in VS Code.
2. Open `function.html` in your browser (double-click it from File Explorer).
3. Press `F12` and choose the **Console** tab.
4. In `function.html`, change the filename in `<script src="01-simple-interest.js"></script>` to the program you want to run, for example `02-check-number.js`.
5. Save `function.html`, refresh the browser, and answer the prompt boxes.
6. Read the output in Console.

Each JavaScript file uses `prompt()` for input and `console.log()` for output, so it is intended to run from `function.html` in a browser.
